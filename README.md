# bio-pipelines

Clinical and bioinformatics pipelines built as portfolio projects.

## Contents

- **[HEMA-CORE](./HEMA-CORE%20README.md)** — Unified hematology pipeline: blood compatibility, CBC interpretation, Rh-pregnancy risk. Streamlit + MySQL. 10 pytest tests.
- **METABO-CORE** — Merged metabolic + pharmacokinetics pipeline. *In progress.*

## Stack

Python · Streamlit · pandas · matplotlib · MySQL · pytest
