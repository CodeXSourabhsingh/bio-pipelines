# bio-pipelines

Clinical and bioinformatics pipeline projects built as portfolio work to demonstrate healthcare data analysis, decision-support workflows, and applied data science in a biomedical context.

This repository brings together focused projects exploring clinical interpretation, laboratory data processing, and interactive analytics with healthcare relevance.

## Projects

- **[HEMA-CORE README](https://github.com/CodeXSourabhsingh/bio-pipelines/blob/main/HEMA-CORE%20README.md)** — Unified hematology pipeline for blood compatibility analysis, CBC interpretation, and Rh pregnancy risk assessment. Built with Streamlit and MySQL. Includes 10 pytest tests.
- **METABO-CORE** — Integrated metabolic and pharmacokinetic analysis pipeline. Currently under development and focused on metabolite analysis combined with drug exposure modeling.

## Live Demo

## Why this repository exists

- Showcases practical bioinformatics and clinical data workflows
